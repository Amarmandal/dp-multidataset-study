# LiRA Cross-Dataset Comparison Figures

Colour-synced comparison plots summarising the LiRA findings across all six
study datasets. Generated by [`../make_comparison_figures.py`](../make_comparison_figures.py)
from the per-dataset `results/<DATASET>/<DATASET>_lira_results.csv` files.

**Colour conventions (consistent across every figure and with `run_lira.py`):**
- Models — LR `#1f77b4` (blue), RF `#d62728` (red), GNB `#2ca02c` (green), SVM `#9467bd` (purple), DNN `#ff7f0e` (orange)
- Datasets, ordered small → large `n_train` — GALLSTONE (red), BCP (green), CANCER_RISK (orange), KIDNEY_STONE (blue), LUNG_CANCER (purple), DIABETES (brown)
- Headline metric — **TPR @ 1% FPR** (random baseline = 0.01); attack AUC baseline = 0.5

| # | File | What it shows |
|---|------|---------------|
| 1 | `01_standard_leakage_bars.png` | Worst-case leakage of every Standard model across all datasets. |
| 2 | `02_dataset_size_effect.png` | Standard-model TPR@1% vs training-set size (log x) — leakage decays toward baseline as n grows. |
| 3 | `03_gallstone_std_vs_dp.png` | GALLSTONE Standard vs best-ε DP per model. |
| 4 | `04_dp_rf_tpr_vs_epsilon.png` | DP-RF leakage vs ε across datasets, with each dataset's Standard baseline (dashed). |
| 5 | `05_standard_auc_heatmap.png` | Attack-AUC heatmap (models × datasets, Standard). |
| 6 | `06_gallstone_rf_privacy_utility.png` | GALLSTONE-RF privacy (leakage) vs utility (accuracy) vs ε — the trade-off DP makes. |

> The checked-in `.png` files predate the dataset change and still show the old
> four-dataset run. Re-run the generator to refresh them.

Regenerate with:

```bash
cd Attack/LiRA && python3 make_comparison_figures.py
```
